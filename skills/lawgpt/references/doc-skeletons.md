# 文书类型骨架

每类文书问三个问题：**法定要素有哪些（不能漏）／该省的可以不写吗／实务上法官最先看哪里。**

---

## 一、民事起诉状

**法定依据**：《民事诉讼法》（2023 修正）第 124 条（记明事项）、第 122 条（起诉条件，立案时审查）。

| 段 | 必备内容 | 易错 |
|---|---|---|
| 标题 | 民事起诉状 | 写"起诉书"（刑案用语） |
| 原告 | 自然人：姓名、性别、年龄、民族、职业、工作单位、住所、联系方式；法人：名称、住所、法定代表人姓名职务、联系方式 | 漏联系方式；法人漏法定代表人 |
| 被告 | 自然人：姓名、性别、工作单位、住所等；法人：名称、住所等 | 被告人数不清、住所不具体（直接影响送达与管辖） |
| 诉讼请求 | 逐项编号；给付之诉须有金额与计算方式；利息写到"至实际清偿之日止" | "赔偿损失"无金额；多项请求未分项 |
| 事实与理由 | 按要件分节，不按时间流水账；每节以"事实 + 证据 + 法律"三段收尾 | 通篇情绪叙述；事实与请求不对应 |
| 证据 | 名称、来源、待证事实；附证据清单与份数 | 只列名称，不写待证事实 |
| 尾部 | 此致 ××人民法院；具状人签名/盖章；日期；附项（副本份数、证据份数） | 漏"附项"，立案时被退 |

**自检口径**：把第 122 条四项当立案预审表过一遍——原告有直接利害关系、被告明确、请求与事实具体、属受诉法院管辖。

---

## 二、民事答辩状

**法定依据**：第 128 条（答辩状记明事项；收到起诉状副本之日起 **15 日**内提出）。不答辩不影响审理，但放弃的是程序抗辩的时点利益。

| 段 | 必备内容 |
|---|---|
| 答辩人信息 | 同第 128 条所列（自然人七项、法人四项） |
| 答辩请求 | 明确写"请求驳回原告全部诉讼请求"或部分驳回 |
| 程序抗辩 | 管辖异议、主体不适格、重复起诉、仲裁协议、诉讼时效（**这三项优先写，能一击致命**） |
| 实体抗辩 | 逐项对应原告诉请：否认→举证责任在原告；抗辩→己方举证 |
| 质证意见 | 对原告证据的真实性/合法性/关联性逐份表态 |
| 尾部 | 此致法院、答辩人、日期、附项 |

**写法要点**：答辩状不是"再讲一遍故事"，是**拆原告的要件**。按"原告诉请第 N 项 → 其要件 → 哪一要件不成立 → 依据"的结构写，比按时间顺序写有效得多。

## 三、民事上诉状

**法定依据**：第 172 条（当事人信息、原审法院名称与案号案由、上诉请求和理由）；第 171 条（判决 15 日、裁定 10 日）。

| 段 | 必备内容 | 易错 |
|---|---|---|
| 当事人 | 上诉人与被上诉人信息，注明原审诉讼地位（"一审原告"） | 漏注原审地位 |
| 原审信息 | 原审法院名称、案号、案由 | 案号写错导致移卷延误 |
| 上诉请求 | 撤销/改判/发回重审，逐项写清；改判的写明改判内容 | 只写"请求改判"未写改判成什么 |
| 上诉理由 | 分"认定事实错误""适用法律错误""程序违法"三类，每类下逐点对应判决书原文段落 | 通篇重复一审主张，不针对判决理由 |
| 尾部 | 此致 ××中级人民法院（上一级）；上诉人；日期；副本份数 | 递回原审法院还是二审法院搞错（应通过原审法院递交） |

**写法要点**：上诉状唯一的靶子是**一审判决书的理由部分**。每一条理由都要"引用判决原话 → 指出错误 → 给出正确认定"。

## 四、代理词（法庭辩论意见）

无法定格式，属实务文书。结构服务于"让法官在争议焦点上采纳己方"。

1. **抬头**：审判长、审判员
2. **身份与授权**：受谁的委托、作为何种诉讼代理人
3. **争议焦点归纳**（关键一步：把庭审焦点锁定在对己方有利的框架里；焦点归纳错，后面全废）
4. **逐项论证**：每一焦点 → 己方观点 → 证据支撑（指明证据编号与页码）→ 法律依据 → 反驳对方主张
5. **结论**：明确请求支持/驳回哪几项
6. **落款**：代理人、律所、日期

**禁忌**：不复述庭审过程；不写"综上，请求法院依法判决"这种无功收尾——结论必须落到具体请求项。

## 五、律师函

非诉文书，兼具催告与固定证据作用（发出即产生催告效力，影响时效与违约金起算）。

| 段 | 内容 |
|---|---|
| 函件编号与收件人 | 编号便于归档；收件人须为有处分权的主体 |
| 委托人及授权 | 载明受托关系与授权范围 |
| 事实陈述 | 只写有证据支撑的事实，用"据委托人提供的××（证据）显示"句式 |
| 法律分析 | 定性 + 责任构成 + 法律后果 |
| 要求 | 具体行为 + 明确期限（如"收函之日起 7 日内"）+ 金额与账户 |
| 后果告知 | 逾期将采取的措施（诉讼/保全/报案）——**须为可实际执行者，虚张声势会削弱后续函件效力** |
| 落款与送达 | 律所盖章、律师签名、联系方式；建议用 EMS 并在面单注明"律师函" |

## 六、法律意见书

| 段 | 内容 |
|---|---|
| 委托事项与范围 | 明确"就××事项出具"，并声明范围外事项不在本意见覆盖内 |
| 声明与假设 | 材料真实性由委托人负责；不构成对交易商业可行性的判断 |
| 事实与材料清单 | 逐项列已审阅文件，注明版本与日期 |
| 分析 | 分点，每点"问题—依据—结论" |
| 结论与建议 | 分级表述：确定结论 / 附条件结论 / 无法形成结论 |
| 落款 | 出具单位、承办律师、日期、附件 |

**红线**：结论分级必须诚实标注。"无法形成结论"是合法且常见的结论，硬凑确定结论是执业风险。

## 七、程序申请书（保全／调查取证／延期举证／执行）

| 段 | 内容 |
|---|---|
| 申请人/被申请人 | 基本信息 |
| 请求事项 | 一句话，可执行（保全须写标的物、金额、措施类型） |
| 事实与理由 | 紧迫性/必要性 + 与本案请求的关联 |
| 担保 | 保全申请须写担保方式与担保物（**漏写必被驳**） |
| 落款 | 此致法院、申请人、日期 |

> 保全、调查取证的条号（民诉法保全章、证据章）**本文件未核验，引用前现查**。
